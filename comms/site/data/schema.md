# Experiment Data Schema

The site generator reads two file types from `comms/site/data/` (files starting
with `_` are ignored). Files are auto-detected by structure.

## 1. `manifest.json` — ExperimentManifest

Written by the experiment framework to `<output_dir>/manifest.json` after each
run. Copy or symlink it into `data/` to populate the Overview and Results pages.

```json
{
  "experiment_name": "fuzzing-baseline",
  "config": {
    "name": "fuzzing-baseline",
    "description": "Baseline fuzzing runs on Tier 1 parser targets",
    "task": "fuzzing",
    "output_dir": "results/fuzzing-baseline",
    "repetitions": 1,
    "defaults": {
      "engine": "libfuzzer",
      "fuzz_duration": 7200,
      "max_rounds": 4,
      "round_duration": 1800,
      "targets_root": "../targets"
    },
    "grid": {
      "model": ["anthropic/claude-sonnet-4-6", "anthropic/claude-opus-4-6"],
      "target": ["libpng", "libjpeg-turbo", "libxml2", "zlib"],
      "extra": {}
    }
  },
  "runs": {
    "<run_id>": {
      "run_id": "<12-hex-char SHA-256 hash>",
      "model": "anthropic/claude-sonnet-4-6",
      "target": "libpng",
      "repetition": 0,
      "task_kwargs": {
        "engine": "libfuzzer",
        "fuzz_duration": 7200,
        "max_rounds": 4,
        "round_duration": 1800
      },
      "status": "completed",
      "eval_log_path": "results/fuzzing-baseline/<run_id>.eval",
      "started_at": "2026-03-01T22:00:00+00:00",
      "completed_at": "2026-03-02T00:18:00+00:00",
      "error": null
    }
  },
  "created_at": "2026-03-01T21:58:00+00:00",
  "updated_at": "2026-03-02T01:15:00+00:00"
}
```

### `status` values

| Value | Meaning |
|-------|---------|
| `pending` | Not yet started |
| `running` | Currently executing (or stuck if process died) |
| `completed` | Finished successfully; `eval_log_path` is set |
| `failed` | Terminated with error; `error` field has the message |

## 2. `analysis.json` — ExperimentAnalysis

Generated by:
```bash
uv run parser-security-eval experiment analyze <output_dir> \
  --json comms/site/data/analysis.json
```

Populates the Breakdowns page (CWE, difficulty, target charts).

```json
{
  "experiment_name": "patching-model-sweep",
  "task_type": "patching",
  "leaderboard": [
    {
      "model": "anthropic/claude-opus-4-6",
      "mean_score": 0.71,
      "patch_applies_rate": 0.90,
      "compiles_rate": 0.85,
      "crash_eliminated_rate": 0.75,
      "tests_pass_rate": 0.65,
      "mean_input_tokens": 18420.0,
      "mean_output_tokens": 2841.0,
      "mean_total_time": 52.3,
      "n_samples": 20
    }
  ],
  "cwe_breakdown": [
    { "model": "anthropic/claude-opus-4-6", "cwe": "CWE-120", "mean_score": 0.82, "n_samples": 4 }
  ],
  "difficulty_breakdown": [
    { "model": "anthropic/claude-opus-4-6", "difficulty": "easy", "mean_score": 0.91, "n_samples": 6 }
  ],
  "target_breakdown": [
    { "model": "anthropic/claude-opus-4-6", "target": "libpng", "mean_score": 0.78, "n_samples": 5 }
  ]
}
```

## Auto-detection

The builder detects file type by structure:

| Condition | Detected as |
|-----------|-------------|
| `"runs"` is a `{}` dict **and** `"experiment_name"` present | manifest |
| `"leaderboard"` list **and** `"task_type"` present | analysis |
| Anything else | skipped (warning printed) |

Both files can coexist in `data/` — the builder loads both.
